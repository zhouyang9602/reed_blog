判断一个网页是否好读，往往发生在几秒钟内，而且很难说清原因。

不是字体不够漂亮，也不是颜色不够高级。更多时候，问题藏在一些很小的数字里：行高太紧、行长太宽、段落之间没有呼吸、辅助文字和背景太接近。

排版不是装饰。它决定读者的眼睛如何在页面上移动。

## 一、控制行长

一行字太长，眼睛从行尾回到下一行开头时会迷路；太短，又会不断打断阅读节奏。

中文正文比较舒服的宽度大约在 28 到 38 个字之间。英文内容通常建议每行 60 到 75 个字符。

在 CSS 中，不要只依赖容器宽度：

```css
.prose {
  max-width: 68ch;
  margin-inline: auto;
}
```

`ch` 不是绝对长度，它会根据当前字体变化。对中英文混排的文章，通常比固定像素更稳。

## 二、让行高匹配字号

标题需要紧凑，正文需要舒展。

一级标题的行高可以是 1.2，因为大字号本身已经有足够空间；正文通常适合 1.7 到 1.9。行高太小会让文字挤在一起，太大又会让段落失去整体感。

```css
:root {
  --leading-title: 1.25;
  --leading-body: 1.8;
  --leading-tight: 1.5;
}
```

比具体数值更重要的是层级：标题、正文、注释之间的行高应当有可感知的差异。

## 三、段落间距要大于行间距

段落之间的空白，是读者区分思路的停顿。

如果段间距和行间距差不多，整页会像一块没有分段的文字墙。一个简单的经验是：段间距至少是行间距的 0.6 到 0.8 倍。

```css
p {
  margin: 0 0 1.25em;
  line-height: 1.8;
}
```

不要用多个 `<br>` 制造空白。结构问题应该用结构与间距解决，而不是塞入没有语义的换行。

## 四、文字对比度不是越黑越好

纯黑文字放在纯白背景上，对比度很高，但长时间阅读容易疲劳。稍带蓝灰的深色会更柔和。

同时，辅助信息不能浅到无法阅读。日期、标签和说明文字即使字号较小，也应该保持足够的对比。

一个实用的检查方法是眯起眼睛看页面：如果次要信息完全消失，它可能太浅了。

## 五、给链接一个稳定的身份

在正文中，链接应该一眼可识别，但又不能把段落切得七零八落。

下划线是最可靠的提示，尤其是对色觉障碍用户。可以降低下划线的对比度，在 hover 时加强：

```css
.prose a {
  color: #2468e8;
  text-decoration: underline;
  text-decoration-color: rgba(36, 104, 232, 0.3);
  text-underline-offset: 0.18em;
}

.prose a:hover {
  text-decoration-color: currentColor;
}
```

## 排版是一种照顾

读者不会因为某个行高正好是 1.78 而称赞你。他们会觉得“这个页面读起来很顺”，然后把注意力留给内容。

好的排版常常是隐形的。它不争夺注意力，只负责让文字以更自然的方式抵达。

当你不知道下一步该优化什么时，可以先从这几件事开始：缩短行长、放宽行高、拉开段落、降低背景噪音，然后把文章从头到尾认真读一遍。

舒适不是抽象的感觉，它通常对应着具体而微小的选择。
